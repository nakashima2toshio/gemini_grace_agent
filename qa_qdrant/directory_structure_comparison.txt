"""
┌─────────────────────────────────────────────────────────────────────────┐
│                     📦 インポートパスの問題と解決                        │
└─────────────────────────────────────────────────────────────────────────┘

問題: qa_qdrant/ に移動すると、親ディレクトリのモジュールが見つからない
─────────────────────────────────────────────────────────────────────────

【移動前（ルートから実行）】
project_root/make_qa.py:
    from qa_generation.pipeline import QAPipeline  ✅ OK
    from config import DATASET_CONFIGS             ✅ OK

    Python実行時のカレントディレクトリ: project_root/
    sys.path[0]: project_root/


【移動後（修正なし）】
project_root/qa_qdrant/make_qa.py:
    from qa_generation.pipeline import QAPipeline  ❌ ModuleNotFoundError
    from config import DATASET_CONFIGS             ❌ ModuleNotFoundError

    Python実行時のカレントディレクトリ: project_root/qa_qdrant/
    sys.path[0]: project_root/qa_qdrant/

    問題: qa_generation/ が見つからない（親にある）


【移動後（修正済み）】
project_root/qa_qdrant/make_qa.py:
    import sys, os
    sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
    ↓
    sys.path[0] に project_root/ が追加される

    from qa_generation.pipeline import QAPipeline  ✅ OK
    from config import DATASET_CONFIGS             ✅ OK


図解:
─────────────────────────────────────────────────────────────────────────
                     __file__ の解決過程

/path/to/project_root/qa_qdrant/make_qa.py  ← __file__ (実行中のファイル)
         ↓
os.path.abspath(__file__)
         ↓
/path/to/project_root/qa_qdrant/make_qa.py
         ↓
os.path.dirname(...)  【1回目】
         ↓
/path/to/project_root/qa_qdrant
         ↓
os.path.dirname(...)  【2回目】
         ↓
/path/to/project_root  ← PROJECT_ROOT（これを sys.path に追加）
"""

"""
┌─────────────────────────────────────────────────────────────────────────┐
│                   📁 ファイルパス参照の問題と解決                        │
└─────────────────────────────────────────────────────────────────────────┘

問題: 相対パスで指定した出力先が想定と異なる場所になる
─────────────────────────────────────────────────────────────────────────

【移動前】
実行: project_root/ から実行
    $ python make_qa.py --output qa_output/pipeline

コード:
    output_dir = "qa_output/pipeline"  # 相対パス

結果:
    project_root/qa_output/pipeline/qa_pairs_*.csv  ✅ 期待通り


【移動後（修正なし）】
実行: project_root/ から実行
    $ python qa_qdrant/make_qa.py --output qa_output/pipeline

コード:
    output_dir = "qa_output/pipeline"  # 相対パス

結果:
    project_root/qa_output/pipeline/qa_pairs_*.csv
    ↑ 実行ディレクトリ（project_root/）からの相対パスなので
       たまたま正しい場所に出力される

    しかし、もし qa_qdrant/ に cd してから実行すると:
    $ cd qa_qdrant
    $ python make_qa.py --output qa_output/pipeline

    project_root/qa_qdrant/qa_output/pipeline/qa_pairs_*.csv  ❌ 違う場所


【移動後（修正済み）】
コード:
    PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
    output_dir = os.path.join(PROJECT_ROOT, "qa_output", "pipeline")
    # → /path/to/project_root/qa_output/pipeline

結果:
    どこから実行しても:
    project_root/qa_output/pipeline/qa_pairs_*.csv  ✅ 常に正しい


図解:
─────────────────────────────────────────────────────────────────────────
相対パス vs 絶対パス

【相対パス】（推奨されない）
    "qa_output/pipeline"
    ↓
    カレントディレクトリ依存
    - project_root/ から実行 → project_root/qa_output/pipeline ✅
    - qa_qdrant/ から実行   → qa_qdrant/qa_output/pipeline ❌

【絶対パス】（推奨）
    os.path.join(PROJECT_ROOT, "qa_output", "pipeline")
    ↓
    /absolute/path/to/project_root/qa_output/pipeline
    ↓
    どこから実行しても同じ場所 ✅
"""
