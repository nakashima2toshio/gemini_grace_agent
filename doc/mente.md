# メンテナンス記録

## 2025-12-30: [REVERTED] make_qa.py のDNSエラー修正 (Monkey Patch)

### 概要
`make_qa.py` の実行時、Celeryワーカーが一斉に Gemini API (`count_tokens`) を呼び出すことで DNS解決エラー (503 Service Unavailable) が発生していた問題への対処。

### 結果
**失敗。切り戻し済み。**
`make_qa.py` (投入側プロセス) にパッチを適用しても、別プロセスで動く Celeryワーカー (実行側プロセス) にはパッチが反映されないため、効果がなかった。
